# Contributing to the GH-300 Study Guide

- **Improve study notes.** Start with the matching objective in the [official GH-300 guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-300). Write an original explanation and use small, reproducible examples.
- **Add official references.** Link directly to the relevant GitHub Docs or Microsoft Learn page. Verify the feature and any plan, platform, or policy conditions that affect the example.
- **Report outdated features.** Open an issue with the page, wording, current official reference, and any relevant editor or CLI version. Label historical behavior clearly when it still helps explain the topic.
- **Propose translations.** Mirror the English route under `docs/fr/`. Keep the objective, examples, and references in sync. Translate explanations and preserve literal commands and identifiers.
- **Submit a pull request.** Use a topic branch, run `npm run docs:build`, and preview the affected pages in both languages. Summarize what changed and list the official sources used. Include screenshots for visual changes.

Write original practice exercises. Exclude leaked or recalled certification questions.
