# Défi pratique / Hands-on challenge

## Français — Résumer des tâches

Créez une fonction `summarizeTasks(tasks)` qui compte les tâches ouvertes et terminées dans une liste d’objets. Chaque tâche contient un titre et un statut `open` ou `done`.

1. Demandez à Copilot de proposer des cas de test pour une liste vide, une liste mixte et un statut inconnu. Décidez du comportement attendu pour le statut inconnu.
2. Donnez à Copilot les résultats attendus, puis demandez une première implémentation. Relisez le code et vérifiez que la liste d’origine reste intacte.
3. Exécutez les tests. Corrigez les écarts et notez les précisions du prompt qui ont amélioré le résultat.

**Livrable** — La fonction, ses tests et un court exemple de requête affinée.

## English — Summarize tasks

Create a `summarizeTasks(tasks)` function that counts open and completed tasks in an array of objects. Each task has a title and either an `open` or a `done` status.

1. Ask Copilot to suggest test cases for an empty array, a mixed array, and an unknown status. Decide how the function should handle the unknown status.
2. Give Copilot the expected results and ask for an initial implementation. Review the code and check that the input array stays intact.
3. Run the tests. Fix any discrepancies and record which prompt details improved the result.

**Deliverable** — The function, its tests, and a short example of a refined prompt.
