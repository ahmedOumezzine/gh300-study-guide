# Ressources d’apprentissage

Les six domaines suivent le guide Microsoft, avec les compétences évaluées au **7 août 2026**. Les noms de produits, les fonctionnalités et les écrans d’administration évoluent : utilisez toujours la source officielle pour les détails actuels.

## Vue d’ensemble de l’examen

| Domaine | Pondération | À réviser |
| --- | --- | --- |
| Utiliser GitHub Copilot de manière responsable | 15–20 % | Risques, éthique, préjudices, atténuation, validation |
| Utiliser les fonctionnalités de GitHub Copilot | 25–30 % | IDE, CLI, mode Agent, capacités, politiques |
| Comprendre les données et l’architecture | 10–15 % | Flux, requête, filtrage, cycle de vie, limites |
| Concevoir les requêtes et le contexte | 10–15 % | Structure, contexte, zero-shot, few-shot, historique |
| Améliorer la productivité | 10–15 % | Génération, refactorisation, documentation, tests, sécurité |
| Configurer la confidentialité et les protections | 10–15 % | Exclusions, éditeur, code public, diagnostic |

- [Guide officiel GH-300](https://learn.microsoft.com/fr-fr/credentials/certifications/resources/study-guides/gh-300)
- [Documentation GitHub Copilot](https://docs.github.com/fr/copilot)
- [Formation Microsoft Learn](https://learn.microsoft.com/fr-fr/training/)
- [GitHub Skills](https://skills.github.com/)

## Préparer l’examen

- Lire la [page de certification Microsoft](https://learn.microsoft.com/fr-fr/credentials/certifications/github-copilot/).
- Tester le [bac à sable de l’examen](https://aka.ms/exam-sandbox) pour connaître l’interface.
- Utiliser l’[évaluation pratique officielle](https://learn.microsoft.com/fr-fr/credentials/certifications/exams/gh-300/) lorsqu’elle est disponible dans votre région.
- Tenir un journal des fonctionnalités vérifiées, notamment les fonctionnalités en préversion et les contrôles d’administration.
