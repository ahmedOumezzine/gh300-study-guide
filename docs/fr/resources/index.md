# Ressources d'apprentissage

Les six domaines suivent les competences du guide Microsoft, evaluees au **7 aout 2026**. Les noms de produits, les fonctionnalites et les ecrans d'administration evoluent : utilisez toujours la source officielle pour les details actuels.

La liste resumee de la page Microsoft repete actuellement la ligne des fonctionnalites Copilot ; les sections detaillees definissent six domaines uniques, suivis par ce guide.

## Vue d'ensemble de l'examen

| Domaine | Ponderation | A reviser |
| --- | --- | --- |
| Utiliser GitHub Copilot de maniere responsable | 15-20 % | Risques, ethique, prejudices, attenuation, validation |
| Utiliser les fonctionnalites de GitHub Copilot | 25-30 % | IDE, CLI, mode Agent, capacites, politiques |
| Comprendre les donnees et l'architecture de GitHub Copilot | 10-15 % | Utilisation et flux, construction, filtrage, cycle de vie, limites |
| Appliquer la conception des prompts et du contexte | 10-15 % | Structure, contexte, zero-shot, few-shot, flux et historique |
| Ameliorer la productivite avec GitHub Copilot | 10-15 % | Generation, refactorisation, documentation, tests, securite, performance |
| Configurer la confidentialite, les exclusions de contenu et les protections | 10-15 % | Exclusions, parametres de l'editeur, code public, diagnostic |

- [Documentation GitHub Copilot](https://docs.github.com/fr/copilot)

- [Notes de reference de Marco Grimaldi](https://marcogrimaldi29.com/gh-300-study-notes/) (guide communautaire independant ; verifier les details aupres de Microsoft et GitHub)

## Preparer l'examen

- Lire la [page de certification Microsoft](https://learn.microsoft.com/fr-fr/credentials/certifications/github-copilot/).
- Tester le [bac a sable de l'examen](https://aka.ms/exam-sandbox) pour connaitre l'interface.
- Utiliser l'[evaluation pratique officielle](https://learn.microsoft.com/fr-fr/credentials/certifications/github-copilot/?practice-assessment-type=certification) lorsqu'elle est disponible dans votre region.
- Tenir un journal des fonctionnalites verifiees, notamment les fonctionnalites en preversion et les controles d'administration.
