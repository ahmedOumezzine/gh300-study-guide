# Learning resources

The six domains follow the Microsoft study guide skills measured as of **August 7, 2026**. Product names, feature availability, and administration screens can change, so use the official source for the latest detail.

## Exam scope at a glance

| Domain | Weight | What to revise |
| --- | --- | --- |
| Use GitHub Copilot responsibly | 15–20% | Risks, ethical use, harms, mitigation, validation |
| Use GitHub Copilot features | 25–30% | IDE, CLI, Agent Mode, capabilities, policies |
| Understand data and architecture | 10–15% | Data flow, prompt building, filtering, lifecycle, limitations |
| Apply prompt engineering and context crafting | 10–15% | Prompt structure, context, zero-shot, few-shot, chat history |
| Improve developer productivity | 10–15% | Generation, refactoring, documentation, testing, security |
| Configure privacy, content exclusions, and safeguards | 10–15% | Exclusions, editor settings, public-code matching, troubleshooting |

## Exam readiness

- Read the [Microsoft certification page](https://learn.microsoft.com/en-us/credentials/certifications/github-copilot/).
- Try the [exam sandbox](https://aka.ms/exam-sandbox) so the interface is familiar.
- Use the official [practice assessment](https://learn.microsoft.com/en-us/credentials/certifications/exams/gh-300/) when available in your region.
- Keep a change log for Copilot features that you verify, especially preview features and administration controls.
